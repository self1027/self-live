Foram instaladas 15 skills do Superpowers, seis do Ponytail, UI UX Pro Max e
as três variantes do Taste. A variante Taste voltada a páginas públicas exclui
telas de aplicativos; por isso foi usada a orientação de redesign. A interface
mantém fontes do Windows, controles existentes e efeitos discretos, sem novas
bibliotecas ou animações contínuas que disputem GPU com a captura.

A instalação foi feita como skills locais, sem instalar hooks ou plugins de
outros agentes. Os arquivos de skill são locais ao perfil e não são copiados
para este repositório. O [plano](superpowers/plans/2026-10-17-native-automatic-connectivity.md)
registra as verificações e os limites da entrega.
